R Package
RMT4DS

Random matrix tools for data scientists.

  • Provides functions related to the Marchenko–Pastur distribution, Tracy–Widom distribution, and tools for estimation and inference in spiked covariance and signal-plus-noise models.
  • Install from GitHub: library(devtools); devtools::install_github("EthanHuStat/RMT4DS/RMT4DS")
  • GitHub repository
R Package
UHDtst

Two-sample testing for covariance matrices in high dimension.

  • Provides functions for testing equality of covariance matrices in ultra-high-dimensional settings.
  • Install from GitHub: library(devtools); devtools::install_github("EthanHuStat/UHDtst/UHDtst")
